# Trilha TCE-GO (Técnico Administrativo): páginas de estudo

Páginas HTML de estudo da Trilha Estratégica para Técnico de Controle Externo – Técnico Administrativo do Tribunal de Contas do Estado de Goiás (TCE-GO, banca FCC).
Cada página corresponde a uma tarefa da trilha e traz resumo, mapa mental clicável, esquemas, questões interativas com comentário e rendimento, e flashcards com repetição espaçada.

**Site:** https://alexsborne.github.io/tce_go_tec_adm/ (protegido por senha)
